# 事故现场点云勘查与出图系统

交警支队事故科地面三维激光扫描数据的浏览器端勘查系统:TypeScript + WebGPU,无需安装,打开网页即用。原始扫描数据全程只读(证据完整性),所有清理操作走可还原的隔离层。

## 运行

```bash
npm install
npm run dev        # 开发(需要支持 WebGPU 的 Chrome/Edge 113+)
npm test           # 核心算法单元测试(含 0.1% 测量精度验证)
npm run build      # 生产构建
```

## 页面

| 页面 | 功能 |
|---|---|
| 案件列表 | 按事故编号建案;一键生成合成测试场景(已知尺寸车辆 4.8m/5.0m、已知刹车印 23.5m、4 个靶球) |
| 点云导入 | PLY 导入(ASCII / 二进制大小端,颜色+反射强度+法线),坏文件给出具体原因;多站靶球拼接(Horn 四元数法),逐靶球残差表,超限标红 |
| 现场清理 | 统计离群点去除(参数可调)、体素降采样前后点数对比、围观人群/过往车辆拖影识别、框选/套索删点进隔离层、一键还原 |
| 勘查视图 | 椭圆 splat 渲染(法线压扁、近大远小)、真彩色/反射强度/法线/高程着色、八叉树 LOD、路面平面拟合、一键正射俯视、两点测距/三点测角/曲线量长/附着系数估算车速,结果随案件保存 |
| 测量出图 | 正射俯视按 1:200 等比例出图,带比例尺、指北针、测量标注,导出 PNG |
| 设置 | 拼接限差、清理参数、splat 尺寸、LOD 误差、渲染预算 |

## 精度与性能设计

- **测距精度**:合成场景已知尺寸验证误差 < 0.1%(`test/measure.test.ts`):刹车印 23.5m、车长 4.8m(面拟合法)、靶球 40m 基线。拾取点经邻域质心亚采样精化。
- **一千万点 30fps**:八叉树每层按层距保留代表点(Potree 式 LOD),按屏幕误差逐级加载;每帧渲染预算可调(默认 200 万 splat);节点 GPU 缓冲 LRU 缓存 + 每帧限量上传防卡顿;splat 走 instanced draw,一次 draw call 一个节点。
- **证据完整性**:删除只写 flags 隔离层,坐标数组从不修改;测试验证还原后坐标逐字节一致。

## 车速估算公式

v = √(254 · f · s) km/h,f 为路面附着系数(干燥沥青 0.7–0.8,湿滑 0.3–0.5),s 为制动距离(沿刹车印曲线量取)。

## 数据存储

案件、站点、测量记录存 IndexedDB(浏览器本地),点云二进制与元数据分库存储,刷新不丢。
